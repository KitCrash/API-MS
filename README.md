## 📚 Curriculum Breakdown

### Subject 1: Computer Vision (CV) — 5 Units

#### Unit 1: Fundamentals of Image Formation & Enhancement
- **Long Answer Questions**:
  - Q1: Define Computer Vision and list its key applications.
  - Q2: Explain geometric primitives and their importance in image analysis.
  - Q3: Photometric image formation and digital camera model with diagrams.
  - Q4: Role and importance of Fourier Transform in image processing.
  - Q5: 2D Discrete Fourier Transform (DFT) and its significance.
  - Q6: Geometric transformations (Orthogonal, Euclidean, Affine, Projective).
  - Q7: Point operators, linear filtering, and Markov Random Field (MRF) optimization.
  - Q8: Histogram equalization step-by-step image enhancement.
  - Q9: Image restoration techniques and global optimization methods.
  - Q10: Types of spatial filters (mean, Gaussian, median, Sobel, Laplacian).
- **Unit 1 Quick Revision / Complete Recap**: Mathematical formulations, perspective projection, 2D DFT equations, Wiener filter derivation, and exam summary.
- **Unit 1 Short Answer Questions (2 Marks)**: Definitions of Computer Vision, Image Enhancement, Projective Transformation, Filtering Applications, Image Restoration.

#### Unit 2: Image Segmentation & Feature Extraction
- **Long Answer Questions**:
  - Q1: Graph Cut segmentation and Normalized Cuts (N-cut) evaluation.
  - Q2: Feature detectors in computer vision (Harris, FAST, LoG, DoG).
  - Q3: Feature matching process using feature descriptors and NNDR ratio test.
  - Q4: Point, line, and edge features comparison.
  - Q5: Canny edge detector 5-step algorithm.
  - Q6: Split and merge segmentation quadtree decomposition.
  - Q7: Mean shift algorithm and mode-finding clustering.
  - Q8: Feature matching vs feature tracking (KLT optical flow).
  - Q9: Roles of feature detectors vs feature descriptors.
- **Unit 2 Quick Revision / Complete Recap**: N-cut generalized eigensystem, Harris matrix eigenvalues, SIFT 128-D descriptor generation, Canny steps, and comparison tables.
- **Unit 2 Short Answer Questions (2 Marks)**: Image Segmentation, Graph Cut, Normalized Cuts, Mean Shift, SIFT (merged), SURF method, Object Tracking.

#### Unit 3: Motion Estimation & Structure from Motion (SfM)
- **Long Answer Questions**:
  - Q1: Two-Frame and Tomasi-Kanade Factorization Structure from Motion.
  - Q2: Triangulation (DLT) and Bundle Adjustment non-linear optimization.
  - Q3: Two-frame vs constrained structure from motion.
  - Q4: Translation alignment and parametric motion models in dense estimation.
  - Q5: Spline-based motion models (Free-Form Deformations - FFD).
- **Unit 3 Quick Revision / Complete Recap**: Epipolar geometry (baseline, epipoles, epipolar lines), Essential ($E$) vs Fundamental ($F$) matrices, SVD rank-3 theorem, Levenberg-Marquardt bundle adjustment.
- **Unit 3 Short Answer Questions (2 Marks)**: Structure from Motion (SfM), Bundle Adjustment, Epipolar Geometry & Essential Matrix, Dense Motion Estimation.

#### Unit 4: Computational Photography, Image Stitching & Textures
- **Long Answer Questions**:
  - Q1: Motion analysis, optical flow, and Brightness Constancy Constraint.
  - Q2: Panoramic image stitching and global alignment via RANSAC homography.
  - Q3: Composing surfaces and blending methods (Feathering, Multi-band, Poisson).
  - Q4: High Dynamic Range (HDR) radiance capture and Debevec-Malik calibration.
  - Q5: Super-resolution techniques for blur removal and image recovery.
  - Q6: Image matting and compositing with alpha trimaps.
  - Q7: Texture analysis (GLCM) and Efros-Leung synthesis.
- **Unit 4 Quick Revision / Complete Recap**: Optical flow aperture problem, cylindrical panorama warping equations, Laplacian pyramid blending, Poisson gradient editing, closed-form matting.
- **Unit 4 Short Answer Questions (2 Marks)**: Image Stitching, Image Matting, Lumi-graphs, HDR Imaging, Multi-Band Blending.

#### Unit 5: 3D Reconstruction, Rendering & Face Recognition
- **Long Answer Questions**:
  - Q1: 3D reconstruction using Shape from X (Shading, Stereo, Silhouette, Texture).
  - Q2: Point-based (surfels) vs volumetric (voxel grids, TSDF, octrees) representations.
  - Q3: Image-based rendering (IBR) using Layered Depth Images (LDI).
  - Q4: Face detection (Viola-Jones) and pedestrian detection (HOG + SVM).
  - Q5: Turk & Pentland Eigenfaces PCA derivation and 3D shape models.
  - Q6: End-to-end design of face recognition system using Active Appearance Models (AAM).
- **Unit 5 Quick Revision / Complete Recap**: Stereo disparity equation, Viola-Jones 4 core stages (integral image, Haar, AdaBoost, cascade), Dalal-Triggs HOG, Turk-Pentland surrogate covariance matrix, AAM shape/texture synthesis.
- **Unit 5 Short Answer Questions (2 Marks)**: 3D Reconstruction, 3D Object Recognition, Augmented Reality (AR), Eigenfaces, Active Appearance Model (AAM).

#### Final Quick Revision Index (All Units)
- Comprehensive cross-unit topic matrix, mathematical equations cheat-sheet, and canonical algorithm cross-reference across all 5 units.

### Subject 2: API & Microservices (Spring Framework) — 62 Topics
- **Part 1: Spring Core & Dependency Injection (Q1 – Q21)**: Inversion of Control (IoC), Bean scopes, Bean lifecycle callbacks, `@Autowired`, `@Qualifier`, `@Bean`, `@ComponentScan`, `BeanPostProcessor`.
- **Part 2: Spring Boot Architecture & AOP (Q22 – Q34)**: Aspect-Oriented Programming, Pointcuts, Advices (`@Around`, `@Before`), Starters, Auto-configuration, `@SpringBootApplication`, `SpringApplication.run()` bootstrap.
- **Part 3: Spring Data JPA & Persistence (Q35 – Q45)**: Repository hierarchy, Derived query methods, `@Query`, Pagination & Sorting, `@Transactional` propagation and isolation levels, JPA Auditing.
- **Part 4: Web Services & Service-Oriented Architecture (Q46 – Q54)**: SOAP vs REST, WSDL elements, Service Provider-Consumer-Registry (Publish-Find-Bind), Enterprise Service Bus (ESB), SOA vs Microservices, Strangler Fig pattern.
- **Part 5: RESTful APIs, Microservices & Security (Q55 – Q62)**: REST architectural constraints, HTTP status codes, `@RestController`, Global exception handling (`@ControllerAdvice`), JWT & OAuth2, Microservices patterns (API Gateway, Circuit Breaker, Service Discovery).
